# DMs_wBERT

This project includes:

- An analytical paper
- A Jupyter notebook containing the code used for this experiment with a logistic regression baseline to compare against BERT
- Tables and charts included in results.zip from running dm_gender_v2.ipynb

A computational and sociolinguistic analysis of the BERTs (Bi-directional encoder representations from transformers)  LLM gender biases utilizing instances of Discourse Markers in the Spoken BNC 2014 Corpus. 

Final version: DM_gender_paper.pdf 
Final Jupyter Notebook: dm_gender_v2.ipynb

Results contained in results.zip
